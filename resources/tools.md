# DFIR Tools

이 문서는 DFIR 학습에 사용할 도구를 정리하는 공간입니다.

## Forensic Tools

| Tool | Purpose |
|---|---|
| FTK Imager | 디스크 이미지 확인 및 획득 |
| Autopsy | 파일 시스템 포렌식 분석 |
| Volatility | 메모리 포렌식 분석 |
| Wireshark | 네트워크 패킷 분석 |
| CyberChef | 인코딩, 디코딩, 데이터 변환 |
| Sysinternals | Windows 시스템 분석 |

## Notes

각 도구를 직접 실습하면서 사용법과 느낀 점을 추가할 예정입니다.
