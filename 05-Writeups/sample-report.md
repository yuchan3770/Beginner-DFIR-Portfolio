# Sample DFIR Report

## 1. Case Summary

이 문서는 DFIR 실습 보고서 템플릿입니다.

## 2. Objective

제공된 증거에서 의심스러운 활동을 식별하는 것을 목표로 합니다.

## 3. Evidence

- Log file
- PCAP file
- Screenshot
- Analysis notes

## 4. Analysis Steps

1. 파일 기본 정보 확인
2. 타임스탬프 확인
3. 의심 이벤트 식별
4. 정상 행위와 비교
5. 분석 결과 정리

## 5. Findings

아직 실제 분석 결과는 없습니다.  
이 문서는 향후 실습 보고서 작성을 위한 기본 양식입니다.

## 6. Conclusion

분석 과정, 발견 내용, 근거를 명확하게 기록하는 것이 중요합니다.

## 7. Lessons Learned

- 확인한 내용을 반드시 기록한다.
- 의심스럽다고 판단한 이유를 설명한다.
- 증거 없이 결론을 내리지 않는다.
