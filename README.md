# DFIR-Beginner-Portfolio

이 저장소는 DFIR(Digital Forensics and Incident Response) 분야를 공부하며 정리한 초보 포트폴리오입니다.

윈도우 포렌식, 로그 분석, 네트워크 포렌식, 메모리 포렌식, 침해사고 보고서 작성을 중심으로 학습 기록과 실습 내용을 정리합니다.

---

## Goal

이 저장소의 목표는 단순히 이론을 복사해서 모으는 것이 아닙니다.

DFIR을 공부하면서 직접 이해한 내용, 실습 과정, 분석 기록, 보고서 작성 연습을 정리하여 초보 단계의 학습 과정을 포트폴리오 형태로 남기는 것이 목표입니다.
