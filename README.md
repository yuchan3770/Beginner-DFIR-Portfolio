# Beginner DFIR Portfolio

이 저장소는 DFIR(Digital Forensics and Incident Response) 분야를 공부하며 정리한 초보 포트폴리오입니다.

윈도우 포렌식, 로그 분석, 네트워크 포렌식, 메모리 포렌식, 침해사고 보고서 작성을 중심으로 학습 기록과 실습 내용을 정리합니다.

---

## 목표

이 저장소의 목표는 단순 이론 정리가 아니라, 실제 실습 기록과 분석 과정을 포트폴리오 형태로 쌓는 것입니다.

---

## Repository Structure

| Folder | Description |
|---|---|
| `00-Study-Log` | 주간 DFIR 학습 기록 |
| `01-Windows-Forensics` | 윈도우 포렌식 아티팩트 정리 |
| `02-Log-Analysis` | 로그 분석 실습 |
| `03-Network-Forensics` | 네트워크 패킷 분석 실습 |
| `04-Memory-Forensics` | 메모리 포렌식 기초 실습 |
| `05-Writeups` | 실습 보고서 및 분석 리포트 |
| `resources` | 도구, 참고자료, 학습 링크 정리 |
